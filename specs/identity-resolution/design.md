# Design and validation

Reuse the existing 37 unresolved publisher problem keys and immutable pilot.
Inspect primary public AtCoder task pages as a bounded manual verification task,
retaining only authored evidence notes, URLs and access status, not full statement
copies. Earlier bulk statement collection remains disabled. Current terms retain
rights with AtCoder/original holders; inspection does not release text for indexing.
A failed/blocked page remains unavailable, never bypassed.

Compare publisher descriptions against native source task names, contest membership,
semantic objective, explicit constraints and sample values. Contests sharing a task
are appearances, not separate identities. A canonical task's ID can differ from
its contest letter (older ABC/ARC shared tasks); preserve actual IDs and evidence.
CodeNet-origin pNNNNN IDs identify dataset records, not native AtCoder tasks.

Use versioned JSON evidence packets plus a private report; proposed overlays only.
A deterministic builder validates exact coverage, publisher hashes, candidate native
catalog membership, source host and reviewed comparison dimensions before creating
AI-only identity proposals through the existing workbench validator. Keep the
exception where the native source task is absent from the frozen catalog as an
unresolved evidence record for a separately reviewed future catalog addition.

Tests: source hash mismatch, unique/complete coverage, duplicate title with wrong
contest, native task vs contest letter, missing sample/constraint evidence, catalog
absent task, no official-statement ingestion and no verified/approved flag. Review
actual evidence before importing proposals. Existing research hashes and human
confirmation records must stay unchanged.
