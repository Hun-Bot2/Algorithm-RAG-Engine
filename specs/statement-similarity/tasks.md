# Ordered tasks — statement-first research

- [x] S1. Audit repository availability and freeze hashes of existing baselines,
  source assets, provenance and all 3,647 pair records.
- [x] S2. Review current primary-source access policies, API scope, community data
  licenses and first-party license routes; deliver per-platform feasibility report.
- [ ] S3. Establish a verified permitted statement source/use basis for each
  included platform. Record exclusions and missing platforms; do not bypass this gate.
- [ ] S4. Implement collection for cleared sources only; verify canary fetch,
  structured fields, language, raw/content hashes, failures and offline replay.
- [ ] S5. Normalize original tags to a versioned shared taxonomy with reviewed
  relationship types and explicit absent/unmapped states.
- [ ] S6. Detect exact duplicates and create a human-review queue for ambiguous
  cross-platform duplicates, preserving every original identity and text hash.
- [ ] S7. Freeze matched eligible IDs, sections and chunking; compare 384D
  statement MiniLM, statement TF-IDF, tag similarity and hybrid retrieval.
- [ ] S8. Reconcile existing judgment applicability and create method-blind review
  candidates from statement methods, disagreements and random controls.
- [ ] S9. Report baseline quality/resources/coverage; only then test PCA/SVD
  against the original 384D statement embeddings. No automatic model promotion.

Current boundary: S1/S2 are the first deliverable. S3 is not satisfied merely by a
reachable page or a dataset repository's code license. Baseline optimization and
new retrieval/dimensionality-reduction runs are deferred.
