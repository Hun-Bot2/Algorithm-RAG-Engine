# Design

A versioned private node/edge package joins native catalog metadata, normalized
source tags, reused A1 title embeddings and separate statement-run references.
Approved metadata overlays establish source linkage without rewriting frozen data.
Semantic retrieval covers only existing eligible vectors. Algorithm-tag retrieval
and fixed-weight hybrid comparisons operate on a common tagged subset; tags are
imperfect proxy evidence, not verified solution equivalence. AtCoder missing tags
remain unavailable. Every catalog node remains represented even without edges.

Separate reducers reuse A1 vectors: PCA/SVD at 256/128/64D over all represented
rows; 2D nonlinear exploration uses a seeded stratified sample and discloses that
it is not full-catalog coverage. Exact cross-platform neighbor preservation is
computational evidence. Reuse historical judgment evaluation with conditional
metrics and unknown-slot coverage, never filling unjudged labels with zero.

Validate fixtures, all output hashes, source preservation, row counts, platform
boundaries, identity flags, finite vectors and same-population comparisons. An
independent reasoning agent reviews implementation and conclusions before report.
