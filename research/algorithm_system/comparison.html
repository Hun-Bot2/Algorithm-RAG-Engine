Statement-first algorithm similarity study¶

This notebook reads immutable local receipts. The CF+AtCoder publisher-description cohort is separate from the 24,297-row native metadata catalog. LeetCode text is quarantined; AtCoder dataset rows without native IDs are not catalog joins. Existing 3,647 judgments are AI-reviewed, not human gold. Unknown relevance is never a negative. Compression neighbor preservation is not educational utility.
